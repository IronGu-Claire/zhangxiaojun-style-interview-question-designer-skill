# Code of Conduct

Be thoughtful, precise, and respectful.

This project is about improving interview craft. Contributions should help users ask better questions without harassment, defamation, impersonation, or careless factual claims.

## Expected Behavior

- Assume good intent.
- Discuss ideas and implementation details directly.
- Keep criticism specific and actionable.
- Respect privacy and source boundaries.

## Unacceptable Behavior

- Publishing private interview material without permission.
- Adding defamatory or unverified claims about real people.
- Using the skill to impersonate a living person.
- Harassment, threats, or discriminatory language.

Maintainers may remove issues, pull requests, or comments that violate these expectations.
