# 示例输出：唐杰 / 智谱 / GLM

> 这是一个压缩示例，用来展示 skill 的输出风格。正式使用时应继续核实嘉宾最新身份、智谱最新产品、可公开讨论边界和事实来源。

## 采访定位

这次访谈的核心不是“智谱又发布了什么模型”，而是：在中国大模型公司从追赶 GPT-4 进入开源、Agentic、代码、端云一体和商业化混战之后，智谱/GLM 这条路线到底证明了什么，又还没有证明什么。

## 嘉宾画像与信息缺口

- 已知事实：智谱源自清华计算机系知识工程实验室 KEG，GLM 是其核心模型路线。
- 合理推断：唐杰适合被放在“技术创始人 + AI 技术领导者 + Agent 研究转产品”的混合原型里追问。
- 待确认：唐杰在本次采访中以学者、创始团队、公司战略观察者，还是技术负责人身份出现。

## 时长与节奏

建议时长：180 分钟。

## 180 分钟主线结构

- 0-12 min：从 GLM 最近一次能力跃迁切入，建立核心矛盾。
- 12-30 min：从清华 KEG、知识工程、GLM 预训练框架追问判断来源。
- 30-60 min：GLM 技术路线，推理、Coding、Agent 能力如何统一。
- 60-85 min：开源/闭源策略。
- 85-110 min：Agentic LLM 与 AutoGLM。
- 110-135 min：研究、工程、产品、商业化组织如何协同。
- 135-155 min：中国大模型竞争格局。
- 155-170 min：商业化、成本结构和企业市场。
- 170-180 min：未来判断与个人反思。

## 核心问题清单

1. 如果只用一个最近的变化来解释智谱现在的位置，你会选 GLM-4.5/4.6/4.7、AutoGLM、Agentic Coding，还是中国开源模型整体抬升？
2. 外界常把智谱放进“中国大模型六小虎”或者“清华系大模型公司”里理解，你觉得这个标签最准确和最误导人的地方分别是什么？
3. 智谱把愿景写成“让机器像人一样思考”。这句话在 2020 年、2023 年和今天的含义分别发生了什么变化？
4. GLM 这条路线最早吸引你的地方是什么？它是架构判断、工程判断，还是关于通用智能路径的判断？
5. 如果把智谱这几年切成几个阶段，GLM 框架、GLM-130B、ChatGLM、GLM-4、Agentic GLM，每个阶段真正解决的问题是什么？
6. GLM-130B 当年开源时，最难的不是参数量本身，还是训练稳定性、工程系统、成本、中文能力，或者社区信任？
7. 你什么时候第一次意识到：中国公司不是只能做“可用的国产替代”，而是可以在开源模型上做出全球可比较的技术贡献？
8. Agentic LLM 的难点到底在模型本身，还是在环境、工具调用、长期记忆、任务分解、评估体系？
9. 如果拆到底层机制，Coding 能力为什么会成为 Agent 能力的一个关键代理指标？
10. “模型越来越会写代码，所以软件工程会被重写”这个判断成立到什么程度？它现在是产品事实、技术趋势，还是资本叙事？
11. AutoGLM 这类产品最核心的技术挑战是什么：长链路规划、屏幕理解、跨 app 操作、安全边界，还是失败恢复？
12. 一个 Agent demo 什么时候才算从演示变成产品能力？你们内部用什么标准判断它不是碰巧成功？
13. 智谱在开源上走得很前，但大模型公司又需要商业化。你们怎么判断哪些能力应该开源，哪些应该留在 API、产品或企业服务里？
14. 开源模型真正带来的护城河是什么：开发者生态、品牌信任、数据回流、工程反馈，还是对闭源巨头的战略牵制？
15. 如果开源模型性能接近闭源模型，商业模式会不会反而更难？用户为什么还要为模型服务付费？
16. 智谱今天更像模型公司、平台公司、Agent 产品公司，还是企业 AI 基础设施公司？
17. 从 GLM 到 MaaS 到 AutoGLM，你们内部的资源分配怎么变了？更多资源投在预训练、post-training、推理优化、产品工程，还是客户交付？
18. Agentic LLM 很吃 post-training。你们怎么理解 post-training 的战略地位？
19. 中国大模型公司在算力、数据、人才、应用场景上各有约束。智谱最核心的约束是哪一个？
20. 和 DeepSeek 的开源路线相比，智谱想证明的不同命题是什么？
21. 和月之暗面这类技术创始人路线相比，智谱的“清华科研成果转化”基因带来了什么优势和包袱？
22. 外界会质疑大模型公司“技术强，但产品和商业化慢”。这条质疑放在智谱身上，哪部分你觉得成立？
23. 如果今天让你复盘智谱过去三年的一个关键判断，哪一个会坚持，哪一个会改写？
24. 大模型公司组织里，研究员、工程师、产品经理、销售之间最容易互相误解的是什么？
25. 你作为技术出身的人，什么时候意识到模型能力不自动等于公司能力？
26. 企业客户真正买的是模型能力、成本、安全合规、可控交付，还是对未来的战略选项？
27. 如果未来 12-24 个月只能看三个信号来判断智谱路线是否成立，你会看什么？
28. 哪个今天行业里非常热的共识，你认为两年后可能被证明是错的？
29. 如果几年后回看中国大模型这一轮竞争，你觉得它更像技术范式转移、产业国产化、资本周期，还是三者叠加？

## 追问树

- 如果回答偏宏观：能不能落到一次具体模型发布、一次技术路线争论、一次资源重新分配？
- 如果回答偏技术：这个技术能力最后如何体现在用户任务完成率、成本、时延或留存上？
- 如果谈开源：开源后最出乎意料的社区反馈是什么？它真的改变训练或产品路线了吗？
- 如果谈 Agent：请区分“模型会调用工具”和“模型能长期完成任务”之间的距离。
- 如果谈竞争：智谱最怕的竞争对手是哪一类，不是哪家公司，而是哪种能力组合？

## 必问硬问题

1. 智谱最强的能力到底是模型研发，还是把清华科研体系工程化、公司化？
2. 如果开源模型越来越强，智谱怎么避免陷入“技术贡献很大，商业捕获不足”的局面？
3. GLM 的 Agentic 能力里，哪些已经被真实用户证明，哪些还主要停留在 benchmark 或 demo？
4. 智谱有没有把“模型能力提升”误判成“产品市场已经打开”的时刻？
5. 如果这条路线错了，最可能错在开源策略、Agent 方向、商业化节奏，还是组织能力？

## 收束问题

1. 如果只能给 2027 年的智谱留下一个技术判断，你会留下什么？
2. 如果只能给中国大模型创业者一个提醒，你会提醒他们不要高估什么、不要低估什么？
3. 你觉得未来真正的大模型公司，会更像实验室、软件公司、云厂商，还是一种新物种？
4. 这几年对你个人最大的改变是什么：从学术到公司，从模型到产品，从技术到组织，哪一关最难？
