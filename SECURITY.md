# Security Policy

## Reporting Issues

Please open a private security advisory on GitHub if available, or contact the maintainer directly.

## Sensitive Data

Do not commit:

- API keys
- private transcripts
- unreleased interview notes
- unpublished business or funding information
- personal contact information

## Model Output Safety

This skill may generate questions about real people and companies. Users should verify facts from reliable sources before using generated questions in public interviews.
