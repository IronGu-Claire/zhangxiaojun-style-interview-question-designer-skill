# 效果评估方法

用下面的维度判断 skill 是否有效。

## 1. 触发是否稳定

输入：

```text
请使用 $zhangxiaojun-interview-question-designer，为某某设计一份180分钟深度访谈提纲。
背景：……
```

应该输出完整访纲，而不是摘要、新闻稿或泛泛问题列表。

## 2. 嘉宾分型是否合理

测试不同嘉宾：

- 技术创始人：杨植麟、唐杰
- CEO/产品战略家：李想
- 机器人科学家：谭捷
- 口述史型创始人：余凯
- 投资人：戴雨森、Freda、朱啸虎

好的结果会根据嘉宾类型改变主线，而不是换名字套模板。

## 3. 问题深度是否够

检查是否包含：

- 背景观察
- 核心矛盾
- 机制追问
- 具体场景
- 决策取舍
- 失败或反方证据
- 组织和资源分配
- 未来可验证信号

## 4. 长访节奏是否成立

好的访纲应该适合 120/180/240/360 分钟，而不是 30 分钟短访。

## 5. 质量检查脚本

```bash
python3 skill/zhangxiaojun-interview-question-designer/scripts/audit_question_plan.py \
  --input path/to/plan.md
```

评分不是唯一标准，但可以快速发现结构缺失、问题过少、缺少硬问题等情况。
